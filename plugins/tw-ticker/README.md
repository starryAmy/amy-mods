# tw-ticker 1.1.0

Claude 工作時，在輸入框上方顯示台股自選股報價，並可開啟 PTT Stock 版「盤中閒聊」／「盤後閒聊」彈幕。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/twstock` | 顯示目前設定 |
| `/twstock add 2317 2454` | 新增自選股 |
| `/twstock remove 0050` | 移除自選股 |
| `/twstock pin` | 切換常駐顯示 / 只在 Claude 工作時顯示 |
| `/twstock refresh` | 立即更新報價與推文 |
| `/twstock danmaku` | 開關彈幕（預設關閉） |
| `/twstock danmaku width 100` | 設定彈幕寬度上限（格數；實際寬度會自動配合畫面，不會超過） |
| `/twstock block 字詞 ...` | 加入過濾字詞，含這些字的推文不顯示 |
| `/twstock unblock 字詞 ...` | 移除過濾字詞 |

## 彈幕

### 抓哪一串

依台灣時間決定抓 PTT Stock 版**當天**的哪一篇閒聊文：

| 時段 | 抓的文章 |
| --- | --- |
| 週一～週五 09:00–13:30 | 當天的「盤中閒聊」 |
| 週一～週五 13:30 以後（到午夜） | 當天的「盤後閒聊」 |
| 週一～週五 09:00 以前、週六、週日 | 不自動抓 |

- 只看是不是平日，**沒有處理國定假日**；遇到假日還是會照平日的時段去找文章，但通常找不到，盤中時段會顯示「今天的盤中閒聊還沒出現」。
- 找文章的方式：在看板列表的最新兩頁裡，找標題同時含有當天日期（例如 `2026/10/07`）和「盤中閒聊」或「盤後閒聊」的文章，`Re:`、`Fw:` 開頭的不算；有好幾篇符合（例如開了續集）就用最新那篇。
- 每 10 分鐘重新找一次，有續集就自動換過去。
- 13:30 一過換成盤後閒聊時，會清掉盤中閒聊的彈幕，舊推文不再輪播；換日時也一樣。
- 當天的盤中閒聊還沒開串時，狀態列會顯示「今天的盤中閒聊還沒出現」；盤後閒聊還沒開串時彈幕就保持空白，不顯示提示。

### 什麼時候抓、多久抓一次

- 只有在 Claude 工作中（或用 `/twstock pin` 設成常駐）才會抓，閒置時不發請求。
- 每 30 秒檢查一次，但同一篇文章**最多每 90 秒抓一次**；Claude 開始新一輪工作時也會檢查一次。
- 下面這些情況會**馬上強制抓一次**，不受 90 秒間隔和時段限制：
  - `/twstock refresh`
  - `/twstock danmaku` 開啟彈幕
  - `/twstock pin` 切換成常駐
  - 常駐模式下開啟新的 session
- 強制抓的時候如果不在上面任何一個時段（開盤前、週末），會改抓當天的「盤中閒聊」；通常這時還沒開串，所以會看到「今天的盤中閒聊還沒出現」。

### 播放方式

彈幕會記住「這篇文章已經讀到第幾則推文」（不是記時間），用來分辨哪些是新推文：

1. **第一次讀這篇**：把最後 50 則推文放進輪播池，並先播最後 15 則；記下目前的推文總數（例如 320 則）。
2. **之後每次抓**（最快 90 秒一次）：重新抓整篇文章，只把多出來的推文（例如第 321～335 則）排進去播，同時加進輪播池（池子只留最新 50 則）；再把記錄更新成 335。
3. **沒有新推文時**：從輪播池依序重播，彈幕不會停；新推文一進來就優先插播。
4. 新推文太多時只留最新的 80 則排隊。

下面這些情況會從頭重來（回到第 1 步）：

- 換文章：盤中閒聊換盤後閒聊、換日、偵測到續集
- 推文數比上次少（例如文章被修改過）
- 重開 Claude Code：讀到第幾則只記在記憶體裡，不會存檔，所以每個 session 都會從最後 15 則重新開始

其他顯示規則：

- 兩條軌道，每 0.3 秒往左移一格；寬度預設配合畫面，可用 `/twstock danmaku width` 設上限。
- 推＝紅、噓＝綠、→＝預設色；提到自選股代號或名稱的推文以黃色粗體標亮。
- 只顯示推文內容，不顯示 PTT 帳號；只有網址的推文、含過濾字詞的推文不顯示。
- 推文不會進入 Claude 的對話。
